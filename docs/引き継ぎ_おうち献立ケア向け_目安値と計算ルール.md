# 引き継ぎ資料：栄養の目安値と、病気が重なったときの計算ルール

- 作成：2026-11-27（食事管理アプリ syokuzi の調査・実装から作成）
- 渡す先：Antigravity で開発中の「おうち献立ケア」
- 使い方：下の「3. 実装指示プロンプト」を、``` の中身ごと Antigravity の開発エージェントに貼り付ける

## 0. 読む前に（大事なこと）

- 数値には、確かめた度合いの印を付けています
  - ✅ 学会・国の資料の原文（PDF）を開いて確かめた
  - ⚠ 一般向けの資料や解説で確かめた（医師向けの原文は読めていない）
  - ❓ 原文が手に入らず確かめていない → **数値は載せていません**。アプリでは「病院の指示を入力してください」と出します
- 目安値の表は、まだ管理栄養士などの専門家に確認していません。利用者さんに使ってもらう前に、専門家の確認を受けてください
- 栄養の数値（料理の塩分・カリウムなど）は、食品成分表から計算します。AIに数値を作らせないでください

## 3. 実装指示プロンプト（ここから下を ``` ごとコピー）

````text
# 指示：「おうち献立ケア」の初期栄養目安値と自動計算処理を、以下の数値・ルールに書き換えてください

あなたは「おうち献立ケア」（食事管理Webアプリ）の実装担当です。
アプリにある「病気・状態ごとの初期目安値」と「目安値の自動計算」「1食の目安との比較」を、
下の【データ】【計算ルール】に合わせて書き換えてください。最後に【受け入れテスト】をすべて自動テストとして実装し、通してください。

## 守ること（安全のきまり）
1. 数値はここに書いたものだけを使う。ここに無い数値を推測で足さない。分からない項目は「病院の指示を入力してください」と表示する（needInstruction）。
2. 主治医・管理栄養士の指示（ユーザーが入力した値）は、どの初期値よりも優先する。画面で「病院の指示」と分かるようにする。
3. 初期値には、出典（下の sourceId と URL）を画面で見られるようにする。
4. 料理・食材の栄養の数値は、日本食品標準成分表（八訂）のデータから計算する。AIに栄養の数値を作らせない。
5. 「この目安は一般的な値で、診断・治療の代わりではない。指示がある場合は指示を優先する」という免責を表示する。
6. 18歳未満の人が病気・状態を選んだ場合、病気ごとの目安は出さず、すべて「主治医の指示を入力してください」とする（基準が大人向けのため）。

## 用語
- 標準体重 SW(kg) = 身長(m) × 身長(m) × 22（小数1桁で丸める）
- BMI = 体重(kg) ÷ 身長(m)²（小数1桁）
- 年齢区分（ageBand）: 1-2, 3-5, 6-7, 8-9, 10-11, 12-14, 15-17, 18-29, 30-49, 50-64, 65-74, 75+（0歳は対象外）
- 活動量（activity）: low / normal / high
- 1日の目安の型:
  - { type: "range", min?, max?, maxExclusive? }（max だけ＝上限、min だけ＝下限、両方＝範囲）
  - { type: "text", text }（数値のない目安。例：「制限なし」「過剰な摂取をしない」）
  - { type: "needInstruction", messages[] }（数値を出さず、病院の指示の入力を求める）
  - { type: "missing", message }（身長・体重など入力が足りない）
  - { type: "instruction", value, compare }（病院の指示。compare = lt(未満)/le(以下)/ge(以上)/about(くらい)）
- 栄養素（nutrient）: energy(kcal), protein(g), fat(g), carb(g), fiber(g), salt(g, 食塩相当量), potassium(mg), phosphorus(mg), water(mL)

### D10. 高血圧・糖尿病 JSH ✅ / JDS2024 ✅ / DRI2025 糖尿病章 ✅
- 高血圧：食塩 6g未満（JSH。2025年版ガイドライン本文は未入手だが、学会資料・解説で6g未満）。
- 糖尿病：食塩 6g未満（JSH：糖尿病・CKDの人には特に6g未満を推奨）。
- 糖尿病のエネルギー：**初期値を出さない（needInstruction：「糖尿病のカロリーは、病院の指示を入力してください」）**。
  理由：JDS2024 は総エネルギー摂取量の目安を2019年版に委ねており、その係数の原文を確認できていないため。
  目標体重の考え方（DRI2025糖尿病章）：BMI 22 を起点とし、20〜25 の幅があり、高齢者は柔軟に個別化。
- 糖尿病の炭水化物：**割合の数値目標にしない**（JDS2024 では三大栄養素比率の規定がなくなり、DRI2025 も特定のバランスが有効とする根拠はないとしている）。表示は量（g）だけ。参考として D8 の 50〜65% を表示するのはよいが、警告には使わない。
- 糖尿病の食物繊維：D7 の目標量を使う。

### D11. 心不全 JCS2025 ✅
- 食塩：**数値の目標は示されていない**（「過剰な塩分摂取を避け、個別性をふまえた塩分管理を考慮する」推奨クラス IIa。1日5〜7.5g の CQ は推奨に至らず）。
  → 初期値なし。ほかの病気に食塩の数値があればそれを使い、無ければ needInstruction（「心不全の塩分は、病院の指示を入力してください」）。
- 水分：代償期の心不全で 1日1〜1.5L を目標とした水分制限を「弱く推奨」（エビデンスレベル A［弱］）。ただし個別に慎重に判断し、脱水・高ナトリウム血症に注意。
  → 初期値は text「制限なし（医師の指示があれば入力）」。1〜1.5L は参考として表示するだけで、指示が無い限り使わない。
- たんぱく質（中等度以上の腎機能障害がない場合）：少なくとも 1.1 g/kg/日、高齢者（アプリでは65歳以上とする）は 1.2〜1.5 g/kg/日（現在の体重で計算）。方向は「不足に注意（下限）」。
- エネルギー：ガイドラインに単一の初期値は無いので、D1 の EER を使う。

### D12. 肝硬変 JSGE2023（患者向け）⚠
- 食塩：腹水がある場合 5〜7g/日（食欲を過度に落とさない程度）。腹水なし：text「控えめに」＋ D4 の目標量。腹水「分からない」：ほかに食塩の数値が無ければ needInstruction（「腹水があるかどうかで変わります。主治医に確かめてください」）。
- 食べ方：1日4〜5回に分ける分割食、就寝前に約200kcal の夜食（LES）。
- たんぱく質：昏睡時以外は極端な制限をしない → text「極端に減らさない」（方向は「不足に注意（下限）」）。
- エネルギー・たんぱく質の数値：医師向けの肝硬変診療ガイドライン2026（改訂第4版）は会員限定で未確認 → **needInstruction**。

### D13. 抗がん剤などの副作用 GANJOHO ✅（数値は置かない。レシピの絞り込みと「コツ」の表示に使う）

## 【計算ルール】病気が重なったとき（そのままコードにできる順番）

各病気・状態は、栄養素ごとに「きまり（rule）」を出す。rule の種類：
- num：{ min?, max?, maxExclusive?, direction? }（direction: "limit"＝減らす向き / "secure"＝減らしすぎない向き）
- text：{ text, direction? }
- block：数値を出さず指示を求める（messages）
- prompt：初期値なし。ほかの病気の数値が無いときだけ指示を求める（心不全の食塩など）
- missing：身長・体重などの入力不足

栄養素ごとに、次の順番で1つの答えにする：
1. ユーザーの指示（instruction）があれば、それを使う（最優先）。根拠の表示用に、下の計算結果も持っておく。
2. block が1つでもあれば → needInstruction（block の messages をすべて表示）。
3. たんぱく質だけ：direction "limit"（腎臓病）と "secure"（心不全・肝硬変）が両方あれば → needInstruction
   「腎臓病では『減らす』、心不全・肝硬変では『減らしすぎない』と、向きが逆になります。病院の指示を入力してください」。
4. missing があれば → missing。
5. num が1つ以上あれば：
   - 下限 = すべての min の最大値（例：CKD の食塩 3g、肝硬変腹水の食塩 5g）
   - 上限 = すべての max の最小値（いちばん厳しい値）。同じ値なら「未満(maxExclusive)」を優先
   - 下限 > 上限（または 下限 = 上限 かつ 未満）なら → needInstruction「病気どうしの目安が食い違っています」
   - prompt と text は、注記として一緒に表示する
6. num が無く prompt があれば → needInstruction（prompt の messages）。
7. それでも無ければ、病気なしの国の目安（base：D1 energy / D4 salt / D5 potassium（CKD を選んでいなければ）/ D6・D7・D8）を使う。text があれば注記として添える。
8. base も無く text だけなら → text。何も無ければ「目安なし」。

リン（phosphorus）：HD/PD のときだけ max = たんぱく質(g)×15。たんぱく質の値は「指示があればその値、無ければ D9 のたんぱく質の上限 × SW」。たんぱく質が決まらなければ needInstruction。
透析以外の CKD では text「数値の目安なし（たんぱく質の量と血液検査で判断）」。

18歳未満で病気・状態を1つでも選んでいれば、病気のきまりはすべて block（「お子さんの病気の目安は、主治医の指示を入力してください」）。病気のない子どもには D1・D4・D5（・D6・D7・D8）を出す。

### 合併時の代表的な注意（ルール外で表示するお知らせ）
- 腎臓病がある人には、D5（カリウムを多めに）を出さない。症状別のコツに出てくる「果物・海藻・きのこ・野菜を多めに」「スポーツドリンク・みそ汁で電解質を」は、腎臓病（カリウム制限）・心不全（食塩）では「担当医に相談してから」と添える。
- 心不全・透析の人には、便秘のコツの「水分1.5〜2L」を出さず、「水分は病院の指示に従ってください」とする。
- ダイエットは、D14 の安全のきまりに当てはまるときは減量の計算をしない。
- 下限（たんぱく質の推奨量・心不全の1.1g/kg など）は、1日の合計で判断する（1食ごとに「少ない」とは警告しない）。

## 【1食あたりの目安】
- 1食の目安 = 1日の目安 × その食事の配分。初期の配分は 朝30%・昼35%・夕35%（設定で変更可、合計100%でなければ保存しない）。
- 比べ方（選んだ料理の1人分の合計と比べる）：
  - 上限（max）：合計 > 上限×配分 で「多め」。未満(maxExclusive)のときは 合計 ≧ 上限×配分 で「多め」
  - 指示が「くらい(about)」、または病気なしのカロリー（min = max）のとき：合計 > 目安×配分×1.1 で「多め」
  - 指示が「以上(ge)」や下限だけのものは、1食では警告しない
  - needInstruction / missing の項目は「目安が決まっていないため比べていません」と表示
- 例：食塩 6g未満 → 朝 1.8g未満・昼 2.1g未満・夕 2.1g未満。カリウム 2,000mg以下 → 朝600・昼700・夕700mg以下。指示 1,600kcal くらい → 夕 560kcal くらい（616kcal を超えたら多め）。
- 家族が複数いるときは、1人ずつ比べる（同じ献立でも、病気のない人は「多め」にならないことがある）。
````
