## 1. 鶏むね肉のしょうが焼き

主菜・約15分　／　1人分：163kcal・たんぱく質20g・食塩0.8g・カリウム466mg・リン210mg・炭水化物11.3g

**材料（1人分）**

| 材料 | g | 目安 | 下ごしらえ |
|---|---|---|---|
| 鶏むね（皮なし） | 80 | 約1/3枚 | そぎ切り |
| 片栗粉 | 3 | 小さじ1 |  |
| 玉ねぎ | 40 | 約1/5個 | 薄切り |
| しょうが | 5 | 1/2かけ | すりおろし |
| しょうゆ（こいくち） | 5 | 小さじ1弱 |  |
| みりん | 6 | 小さじ1 |  |
| サラダ油 | 3 | 小さじ1弱 |  |
| キャベツ | 40 | 葉1枚弱 | せん切り（つけ合わせ） |

**作り方**

1. 鶏むね肉は1cmくらいの厚さにそぎ切りにし、片栗粉を薄くまぶす。
2. しょうがのすりおろし・しょうゆ・みりんを混ぜておく。
3. フライパンに油を熱し、鶏肉を並べて中火で焼く。焼き色がついたら裏返し、玉ねぎを加えて、肉の中まで火が通るまで焼く。
4. 混ぜておいた調味料を加え、全体にからめる。
5. せん切りキャベツと一緒に盛る。

**病気・症状に合わせたコツ**

- **減塩のコツ**：しょうがの香りで、しょうゆが少なくても満足感が出ます。たれは最後にからめ、皿に残ったたれはかけ直さないようにします。
- **カリウムを減らすコツ（腎臓病）**：キャベツはせん切りにしてから水にさらすか、さっとゆでると、カリウムが減ります。
- **たんぱく質の調整（腎臓病）**：肉の量は、たんぱく質の指示に合わせて減らしてください。
- **やわらかく・飲み込みやすく**：そぎ切りにして片栗粉をまぶすと、むね肉でもやわらかく仕上がります。さらに細かく切っても。
- **生もの・衛生**：生ものを避けるよう言われているときは、キャベツは生ではなく、さっとゆでて添えてください。

**生ものの印**：生野菜（「生ものを避ける」を選んだ人には出しません）

**作り方**

1. アルミホイルを広げて玉ねぎを敷き、鮭をのせてこしょうをふる。

- **やわらかく・飲み込みやすく**：鮭は皮と骨を取り、身をほぐしてきのこと一緒に食べると食べやすくなります。
- **口内炎があるとき**：口内炎があるときは、レモンとこしょうを使わず、人肌くらいに冷ましてから食べてください。
- **吐き気があるとき**：ホイルを開けたときの湯気でにおいを感じやすいので、少し冷ましてから開けてください。
- **生もの・衛生**：鮭は中まで火が通っているか確かめてください（身がはしでほぐれる）。

## 9. 豆腐とわかめのみそ汁（だし多めで減塩）

汁物・約10分　／　1人分：35kcal・たんぱく質3.1g・食塩1.1g・カリウム206mg・リン55mg・炭水化物3.2g

**材料（1人分）**

| 材料 | g | 目安 | 下ごしらえ |
|---|---|---|---|
| かつお昆布だし | 150 | 150mL |  |
| 絹ごし豆腐 | 30 | 約1/10丁 | さいの目 |
| 乾燥わかめ | 0.5 | ひとつまみ | 水で戻す |
| 長ねぎ | 5 | 少し | 小口切り |
| みそ（淡色・辛口） | 7 | 小さじ1強 |  |

**作り方**

1. わかめは水で戻す。豆腐はさいの目に、ねぎは小口切りにする。
2. だしを温め、豆腐を入れて温まったら火を弱める。
3. みそを溶き入れ、わかめとねぎを入れて、煮立つ直前に火を止める。

**病気・症状に合わせたコツ**

- **減塩のコツ**：だしをしっかりとると、みそが少なくてもおいしくなります。お椀に半分強の量にすると、さらに塩分が減ります。
- **水分の指示がある方へ**：水分の指示がある方は、汁の量も水分に数えてください。
- **カリウムを減らすコツ（腎臓病）**：汁を少し残すと、カリウムも減ります。
- **吐き気があるとき**：熱いとにおいを感じやすいので、少し冷ましてから。
- **口内炎があるとき**：人肌くらいに冷まして、具はやわらかいものにしてください。
- **下痢のとき**：水分と塩分を一緒にとれるので、下痢のときにも。
- **生もの・衛生**：みそは煮立てる直前まで温めています。生ものや発酵食品を避けるよう言われている方は、みそ汁をとってよいか、医師・管理栄養士に確かめてください。

- **食欲がないとき**：少しずつ、食べられる分だけ。冷ましても食べやすいです。
- **吐き気があるとき**：においが気になるときは、冷ましてから食べてください。
- **口内炎があるとき**：人肌くらいに冷まし、ねぎは入れないでください。
- **下痢のとき**：消化がよく、下痢のときにも食べやすい一品です。
- **生もの・衛生**：卵は固まるまでしっかり火を通してください。
